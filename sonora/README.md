# SONORA Chemistry

The file `thermo-sonora-component.inp` is the thermodynamics for a subset of the SONORA chemistry by Channon Visscher. Channon wrote [a `easyCHEM` tutorial](https://easychem.readthedocs.io/en/latest/content/notebooks/easychem_sonora_2025.html) that uses this input file to reproduce some of the SONORA chemistry. The input file came from [Channon's website](https://github.com/cvisscher/cvisscher.github.io/blob/47bdb66688d6216866c53427cb4e6054c225ad6a/thermofile/thermo-sonora-component.inp). The input file is a truncated species list to approximate the SONORA equilibrium results, and is optimized for chemical equilibrium in a solar composition substellar atmosphere. Channon states that caution should be taken if extending compositions below -1 dex or beyond +1 dex metallicity. This folder contains the script `convert_and_validate.py`, which converts `thermo-sonora-component.inp` to yaml format. Next, the script computes equilibrium with `easyCHEM` and `equilibrate` at a couple different P, T, metallicity and C/O values, confirming the results are close to identical.
